This program provides hands-on experience in launching and configuring an Amazon EC2 Windows Server virtual machine using Amazon Web Services (AWS). Students will learn the fundamentals of cloud computing, Windows Server administration, EC2 instance management, and remote connectivity using Remote Desktop Protocol (RDP).

Students will understand how to select Windows Server Amazon Machine Images (AMIs), configure instance settings, networking, security groups, retrieve administrator credentials, and securely connect to Windows Server instances using Remote Desktop Connection.

Practical Activities:
1. Understand AWS cloud computing and Amazon EC2 fundamentals.
2. Explore EC2 instance types, regions, and availability zones.
3. Launch an EC2 Windows Server instance using an Amazon Machine Image (AMI).
4. Configure instance type, storage, and networking settings.
5. Create and configure security groups to allow RDP access (port 3389).
6. Generate and download an EC2 key pair.
7. Understand Remote Desktop Protocol (RDP) and its working principles.
8. Retrieve the Windows Server administrator password using the private key.
9. Connect to the Windows Server instance using Remote Desktop Connection.
10. Explore the Windows Server desktop environment.
11. Perform basic Windows Server administration and file management.
12. Monitor instance status and manage EC2 resources.
13. Stop, start, and terminate EC2 instances.
Learning Outcome:

Students will gain practical knowledge of creating and managing Windows Server instances on AWS, understanding RDP connectivity, configuring security settings, and remotely administering cloud-based Windows servers. They will develop foundational skills in AWS infrastructure management and Windows Server administration.
