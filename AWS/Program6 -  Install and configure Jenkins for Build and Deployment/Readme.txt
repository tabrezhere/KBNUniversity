This program provides hands-on experience in installing, configuring, and using Jenkins, an open-source automation server widely used for Continuous Integration and Continuous Deployment (CI/CD). Students will learn how to automate application building, testing, and deployment processes using Jenkins pipelines.

Students will understand Jenkins architecture, job configuration, plugin management, source code repository integration, build automation, and deployment workflows.

Practical Activities:
1. Understand Jenkins fundamentals and CI/CD concepts.
2. Install and configure Jenkins on a local system or cloud-based server.
3. Configure Jenkins initial setup and administrator credentials.
4. Explore the Jenkins dashboard and user interface.

Learning Outcome:

Students will gain practical experience in Jenkins installation, configuration, build automation, and application deployment. They will understand how to integrate source code repositories with Jenkins and implement automated CI/CD pipelines following industry-standard DevOps practices
