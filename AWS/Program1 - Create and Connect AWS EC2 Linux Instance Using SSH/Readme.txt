This program provides hands-on experience in launching and configuring an Amazon EC2 Linux virtual machine using Amazon Web Services (AWS). Students will learn the fundamentals of cloud computing, EC2 instance management, Linux operating systems, and secure remote connectivity using Secure Shell (SSH).

Students will understand how to configure EC2 instance settings, select Linux operating system images, configure networking and security groups, generate SSH key pairs, and securely connect to Linux instances using SSH client tools such as Windows PowerShell.

Practical Activities:
1. Understand AWS cloud computing and Amazon EC2 fundamentals.
2. Explore EC2 instance types, regions, and availability zones.
3. Launch an EC2 Linux instance using an Amazon Machine Image (AMI).
4. Configure instance type, storage, and networking settings.
5. Create and configure security groups to allow SSH access.
6. Generate and download an SSH key pair (.pem file).
7. Understand SSH protocol, authentication, and public-private key concepts.
8. Configure SSH key file permissions on Windows.
9. Connect to the Linux instance using Windows PowerShell and SSH commands.
10. Execute basic Linux commands on the remote EC2 instance.
11. Explore Linux file and directory management.
12. Monitor instance status and manage EC2 resources.
13. Stop, start, and terminate EC2 instances.
Learning Outcome:

Students will gain practical knowledge of creating and managing Linux-based EC2 instances, understanding SSH authentication, and securely connecting to cloud virtual machines. They will develop foundational skills in AWS infrastructure management and Linux server administration.
