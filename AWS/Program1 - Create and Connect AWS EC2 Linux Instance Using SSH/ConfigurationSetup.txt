Step1:  Create the instance for Ubunto Image provide the name of instance 

Step2: Copy the downloaded .pem file in D:\KBNUniversity\Program1\student001.pem

Step3:  Get the public IP address

Step4:  Set Inbound rule  SSH to allow 22 portno
In your AWS Console:

Go to EC2 → Instances -> Select your running instance -> Click the Security tab -> Click the attached Security Group -> Select Inbound rules → Edit inbound rules

Add the following: 

Add inbound rule : Type:SSH/Protocol:TCP/Port range :22/ source: My IP

Step5:  open power shell with and execute below command
# Disable inherited permissions
icacls.exe ".\student001.pem" /inheritance:r

# Remove access for other users
icacls.exe ".\student001.pem" /remove "NT AUTHORITY\Authenticated Users"

icacls.exe ".\student001.pem" /remove "BUILTIN\Users"

icacls.exe ".\student001.pem" /remove "Everyone"

# Grant read permission to your Windows account
icacls.exe ".\student001.pem" /grant:r "$($env:USERNAME):(R)"
