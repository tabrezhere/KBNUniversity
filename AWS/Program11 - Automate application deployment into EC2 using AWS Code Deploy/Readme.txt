This program provides hands-on experience in automating application deployment to Amazon EC2 instances using AWS CodeDeploy, a managed deployment service that automates application releases across cloud and on-premises environments.

Students will learn how to configure AWS CodeDeploy, prepare application deployment packages, create deployment groups, configure EC2 instances, and automate application deployment using deployment configurations and scripts.

Practical Activities:
1. Understand Continuous Deployment (CD) concepts and AWS CodeDeploy architecture.
2. Explore AWS CodeDeploy and its deployment lifecycle.
3. Launch and configure an Amazon EC2 instance.
4. Install and configure the CodeDeploy agent on EC2.
5. Create an application deployment package.
6. Create and configure an appspec.yml file.
7. Configure IAM roles and permissions for CodeDeploy.
8. Create a CodeDeploy application and deployment group.
9. Configure EC2 instances as deployment targets.
10. Deploy application files to EC2 using AWS CodeDeploy.
11. Execute deployment scripts and lifecycle hooks.
12. Monitor deployment status and troubleshoot deployment failures.
13. Perform application updates and redeployment.
Learning Outcome:

Students will gain practical experience in automating application deployments to Amazon EC2 using AWS CodeDeploy and understand how Continuous Deployment (CD) simplifies application releases, reduces manual effort, and supports DevOps automation
