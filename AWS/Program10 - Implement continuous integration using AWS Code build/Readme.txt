This program provides hands-on experience in implementing Continuous Integration (CI) using AWS CodeBuild, a fully managed build service that automates application compilation, testing, and build processes.

Students will learn how to configure AWS CodeBuild, connect source code repositories, define build instructions using a buildspec.yml file, and automate application builds whenever code changes are committed to a repository.

Practical Activities:
1. Understand Continuous Integration (CI) concepts and workflows.
2. Explore AWS CodeBuild and its architecture.
3. Create and configure an AWS CodeBuild project.
4. Connect AWS CodeCommit or GitHub as a source code repository.
5. Configure build environments and runtime settings.
6. Create and configure a buildspec.yml file.
7. Define build, test, and artifact generation commands.
8. Configure IAM roles and permissions for CodeBuild.
9. Execute automated application builds.
10. Monitor build logs, troubleshoot errors, and analyze build results.
11. Generate and store build artifacts in Amazon S3.
12. Understand integration of CodeBuild with other AWS DevOps services.
Learning Outcome:

Students will gain practical experience in automating application builds and testing using AWS CodeBuild and understand how Continuous Integration improves software development, code quality, and DevOps workflows.
