This program provides hands-on experience in creating, building, managing, and deploying Docker images using containerization technology. Students will learn how to write a Dockerfile, build a Docker image from an application, and test the image locally using Docker commands.

Students will also explore Amazon Elastic Container Registry (AWS ECR), a fully managed container image repository service. They will learn how to create an ECR repository, configure AWS authentication, connect Docker with AWS ECR, tag Docker images, and push images to the ECR repository.

Practical Activities:
1. Understand Docker images, containers, and containerization concepts.
2. Create a Dockerfile for a sample application.
3. Build a Docker image using Docker commands.
4. Run and test Docker containers locally.
5. Create an Amazon ECR repository.
6. Configure AWS CLI and authenticate Docker with AWS ECR.
7. Tag the locally created Docker image.
8. Push the Docker image to the AWS ECR repository.
9. Verify and manage uploaded Docker images in AWS ECR.
10. Understand how Docker images can be used for cloud application deployment.
Learning Outcome: Students will gain practical knowledge of Docker image creation, container management, and publishing container images to AWS ECR, preparing them for cloud-based application deployment and DevOps workflows.
