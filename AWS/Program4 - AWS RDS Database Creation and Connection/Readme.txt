This program provides hands-on experience in creating, configuring, and managing relational databases using Amazon Relational Database Service (AWS RDS). Students will learn the fundamentals of cloud-based database services, database engine selection, instance configuration, network connectivity, and database administration.

Students will understand how to launch an RDS database instance using supported database engines such as MySQL, PostgreSQL, Microsoft SQL Server, or Oracle. They will also learn how to configure database credentials, security groups, network access, and connect to the database using database client tools.

Practical Activities:
1. Understand AWS RDS and cloud-based relational database concepts.
2. Explore supported database engines: MySQL, PostgreSQL, SQL Server, and Oracle.
3. Create and configure an Amazon RDS database instance.
4. Select database engine, instance class, and storage configuration.
5. Configure database name, username, and password.
6. Configure VPC, subnet groups, and security groups.
7. Enable database connectivity through appropriate network settings.
8. Retrieve the RDS database endpoint and port number.
9. Connect to the database using tools such as MySQL Workbench, pgAdmin, or SQL Server Management Studio.
10. Create databases, tables, and perform basic SQL operations.
11. Insert, update, retrieve, and delete database records.
12. Explore database monitoring, backups, and snapshots.
13. Modify database configurations and manage database instances.
14. Stop and delete RDS instances to manage cloud resources and costs.
Learning Outcome:

Students will gain practical experience in provisioning and managing relational databases on AWS using Amazon RDS. They will understand database connectivity, security configuration, SQL operations, backups, and cloud database administration.
