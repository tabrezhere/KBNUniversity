This program provides hands-on experience in using Git and GitHub for source code management and version control. Students will learn how to track code changes, maintain project versions, manage repositories, and collaborate with other developers.

Students will understand Git fundamentals, local and remote repositories, branching, merging, and how GitHub supports collaborative software development.

Practical Activities:
1. Understand version control systems and Git fundamentals.
2. Install and configure Git on a local system.
3. Configure Git username and email.
4. Create and initialize a local Git repository.
5. Practice essential Git commands such as init, status, add, commit, and log.
6. Create a GitHub account and explore its features.
7. Create and configure remote repositories on GitHub.
8. Connect local repositories to GitHub.
9. Push local code changes to remote repositories.
10. Clone existing GitHub repositories to a local system.
11. Pull and synchronize changes from remote repositories.
12. Create and manage branches.
13. Perform branch merging and resolve merge conflicts.
14. Understand .gitignore and repository management.
15. Collaborate using GitHub repositories and pull requests.
Learning Outcome:

Students will gain practical knowledge of Git and GitHub for version control, source code management, and team collaboration. They will be able to manage repositories, track code changes, work with branches, resolve merge conflicts, and maintain software projects using industry-standard development practices.
